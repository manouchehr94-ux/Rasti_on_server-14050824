# RastiSi — کد Production و CI/CD

مبنای این مخزن، نسخهٔ پاکسازی‌شدهٔ سرور و تغییر favicon شما است.
تغییر در مخزن به‌تنهایی به معنی انتشار روی سرور نیست؛ انتشار و بازگشت دستی‌اند.

- راه‌اندازی: [راهنمای لپ‌تاپ و سرور](docs/deployment/LAPTOP_DEPLOYMENT_FA.md)
- وضعیت و محدودیت‌های واقعی: [گزارش اعتبارسنجی](docs/deployment/INTEGRATION_STATUS_20261115.md)
- کنترل‌های خودکار: بخش **Actions → CI** همین مخزن

## ورودی‌های QA

۳۴۵ تصویر اصلی QA، با تأیید صریح مالک برای انتشار در مخزن عمومی، در دو
آرشیو `tools/ci/assets` حفظ شده‌اند. CI پیش از تست، SHA256 آرشیو و تک‌تک
تصاویر را بررسی و همان فایل‌های اصلی را بازیابی می‌کند؛ تصویر جایگزین تولید
نمی‌شود و تستی حذف نشده است. برای بازیابی محلی، در ریشهٔ مخزن اجرا کنید:

```powershell
py -3 tools/ci/source_inputs.py
```

تصاویر خام، آرشیوهای QA، تست‌ها، مستندات و ابزار توسعه وارد بستهٔ Production
نمی‌شوند. فایل‌های محرمانهٔ سرور و کلیدهای خصوصی داخل این مخزن قرار نمی‌گیرند.

فعال‌سازی نهایی به موفقیت CI، تنظیم محیط `production` در GitHub، اجرای طرح
`Prepare-Production.ps1`، انتقال اولیهٔ تأییدشده و آزمون انتشار/بازگشت واقعی
نیاز دارد. وضعیت این مراحل را در گزارش اعتبارسنجی بخوانید.
